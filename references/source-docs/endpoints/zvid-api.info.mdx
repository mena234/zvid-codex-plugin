Zvid API allows you to programmatically create and manage video rendering jobs, monitor credits, and manage API keys.

## Authentication

Public API endpoints require authentication using an API key. You must:
1. Create an API key via the Zvid dashboard
2. Include the API key in the `x-api-key` header with every request. Endpoints that support dashboard authentication also accept a Bearer JWT in the `Authorization` header.

Example:
```
x-api-key: your-api-key-here
```

## Credits System

Video rendering consumes credits based on:
- Video resolution (width × height)
- Video duration

Make sure you have sufficient credits before submitting render jobs.
